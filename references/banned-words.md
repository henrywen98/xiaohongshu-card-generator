# 小红书违禁词检查 — 说明与替换原则

小红书对违规/敏感用词会**限流、不进推荐池、甚至判违规**。本 skill 在生成卡片和文案时
加入一道合规工序：脚本召回 + 人工（模型）结合上下文精修。

## 工作方式：召回 + 精修（混合）

- **脚本（`scripts/check_banned_words.js`）只负责召回**：按词库 `data/banned-words.json`
  扫出所有疑似违禁词，给出**分类、风险等级、上下文片段、建议替换**。它**不自动改写**。
- **人/模型负责精修**：结合上下文判断是否误报，对真实违禁词做自然替换，保持语义语气不变。

> 为什么不让脚本直接替换？中文是连续文本，子串匹配误报很多——"最近""一起""官方正版"
> 都含敏感子串却无害。机械替换会改坏句子。所以脚本只提示，决定权在上下文。

## 命令

```bash
# 人类可读报告
node scripts/check_banned_words.js path/to/xhs_card_*.html path/to/小红书文案.md

# 结构化 JSON（便于程序/模型处理）
node scripts/check_banned_words.js path/to/小红书文案.md --json

# 严格模式：有高风险命中时退出码为 1（可用于卡流程）
node scripts/check_banned_words.js path/to/小红书文案.md --strict
```

HTML 文件会先**去除标签/CSS/脚本**再扫描，只检测可见文字。

## 词库分类（`data/banned-words.json`）

| 分类 id | 名称 | 风险 | 说明 |
|---------|------|------|------|
| `absolute` | 广告法极限词 / 绝对化用语 | 🔴 高 | 最/第一/顶级/国家级/100%/纯天然… 触发《广告法》 |
| `medical` | 医疗 / 功效宣称违规词 | 🔴 高 | 治疗/根治/抗菌/消炎/减肥/瘦身… 普通商品不得宣称 |
| `diversion` | 营销引流 / 站外导流 | 🔴 高 | 微信/VX/加V/扫码/代购/官网/最低价… 平台重点打击 |
| `platform` | 平台敏感 / 违规营销 | 🟡 中 | 赌博/刷单/高仿/月入过万/震惊体… |

每个词带 `suggest` 建议替换数组（空数组表示建议直接删除或重写）。

## 替换原则

1. **保持语义和语气**：替换后读起来自然，不生硬。
2. **极限词软化**：「最好」→「个人很推荐」、「第一」→「数一数二」、「100% 有效」→「亲测有效」。
3. **功效词改体感**：「治疗痘痘」→「改善痘痘」、「美白」→「提亮肤色」、「减肥」→「身材管理」。
4. **导流词转站内**：「加微信」→「看主页/评论区聊」、「官网」→「品牌主页」、「点击链接」→「见简介」。
5. **拿不准就保守**：高风险词宁可改，标题/正文/标签都要查。

## 维护

词库是普通 JSON，按分类追加 `{ "word": "...", "suggest": ["..."] }` 即可扩展。
小红书规则会变化，建议定期更新（谐音变体如「薇/v信」、新型营销话术等）。
