# 小红书文案套路 — 去 AI 味 + 情绪钩子（必读，适用所有风格）

> 用户的核心痛点：生成的文案"AI 味太重，让人不想看"。AI 味不在于"用没用 AI"，而在于
> **缺真人感**——没有第一人称、没有真实经历、没有情绪、句子太工整、用书面套话。
> 这份清单解决两件事：① 标题/封面有**情绪钩子**（爆款都这么干）；② 正文像**真人口语**。
>
> 用在两处：**封面/卡片文案**（Step 3）和 **正文长文案 `小红书文案.md`**（Step 7）。

---

## 一、标题公式库（决定 80% 点击率）

标题 ≤20 字（最佳 15-18），**关键词前置**，结尾常带情绪/利益钩子。挑一个公式套：

| 公式 | 套路 | 例子 |
|------|------|------|
| 数字结果 | 具体数字 + 成果 | `3 天上手 Claude Code，我再也回不去了` |
| 痛点提问 | 戳痛点 + 反问 | `还在为装不上 Claude Code 抓狂？看这篇` |
| 反认知 | 打破预期 | `不充值 ChatGPT，国产模型也能跑 Claude Code` |
| 画饼承诺 | 快速见效 | `5 分钟，把终端变成 AI 编程搭子` |
| 圈定人群 | 精准身份 | `程序员必存！这个 AI 编程配置我能吹一年` |

### 情绪化标题（小红书最新爆款玩法，**默认就走这个**）

| 玩法 | 结构 | 例子 |
|------|------|------|
| 惊讶开场 | 不是?!现在…这么…啦 | `不是?!现在 Claude Code 这么好装了啦` |
| 反问共鸣 | 我去!没人觉得…吗 | `我去!没人觉得这个 AI 编程神器被低估了吗` |
| 后悔体（FOMO） | 后悔没早知道 | `后悔没早知道🥹白折腾了一整周` |
| 限制体 | 我不允许还有人不知道 | `我不允许还有人不会用 Claude Code` |
| 求助/夸张 | 救命 / 谁懂啊 | `救命谁懂啊😭 这配置一步到位` |
| 趋势揭露 | 其实啊…已经… | `其实啊，终端里写代码的时代真来了` |

> ⚠️ **情绪钩子 ≠ 违禁极限词**。靠"救命/谁懂/后悔"这类**口语情绪词**抓眼球，
> **不要**用"最/第一/国家级/绝对/根治"这类广告法极限词（会被限流，见
> `references/banned-words.md`）。写完标题和正文都要过 `check_banned_words.js`。

## 二、情绪词库（标题和正文都能撒）

`绝绝子 / 救命 / 谁懂啊 / 我去 / 真的会谢 / 我不允许 / 后悔没早知道 / 破防了 /
宝藏 / YYDS / 狠狠心动了 / 直接封神 / 谁还没…啊 / 给我冲 / 嘴替 / 一整个爱住`

称呼读者：`姐妹们 / 家人们 / 宝子们 / 朋友们 / 各位`。
语气词：`其实吧 / 你们啊 / 真的 / 说真的 / 不夸张 / 谁懂`。

> 按内容调浓度：生活/情感/好物类可以撒得猛；硬核技术类克制点，留 1-2 个钩子即可，
> 别让满屏"绝绝子"盖过干货。

## 三、封面文案套路

封面文字 **10-15 字**，一眼能读完。结构 = **钩子 + 一个核心利益/痛点 + 1-2 个高亮关键词**：

- 痛点型：`装 Claude Code 卡到崩溃？这篇救你`
- 身份型：`程序员的 AI 编程搭子，终于来了`
- 结果型：`5 分钟，终端变 AI coding agent`
- 情绪型：`救命这也太好用了吧😭`

配合 dazibao 风格：把**最关键的 2-4 个字**放最大 + 马克笔高亮（如把「能跑」「白嫖」
「保姆级」高亮）。封面别写完整句子，写"会让人想点进去"的半句话。

## 四、口语化长正文框架（Step 7 的主战场，承载干货）

"少图重正文"——卡片只放钩子和要点，**详细干货放这里**。结构（不必死守顺序）：

1. **痛点共鸣开场**（1-2 句，第一人称）
   > 真的，我之前装 Claude Code 折腾到怀疑人生，全网教程都是英文😭

2. **真实经历 / 转折**（带时间线 + 细节 + 之前/现在对比）
   > 直到上周我换了个配置思路，前后不到 10 分钟就跑起来了，当场原地复活。

3. **分点干货**（核心信息，用 emoji 或序号分点，每点短）
   > 1️⃣ 先装好 xxx
   > 2️⃣ 配置里改这一行 👉 ……
   > 3️⃣ 终端输入 xxx，看到 xxx 就成了

4. **互动引导收尾**
   > 卡在哪一步评论区喊我，看到都回～ 觉得有用先码住🙋‍♀️

**真人感要点**：
- 全程**第一人称**（我/我们/咱），讲"我怎么用的"，不是"该工具具有…"。
- 给**具体细节**：时间（"折腾了一周""10 分钟"）、感受、对比、数字。
- **承认不完美**："有点小贵但真香""前期配置麻烦，但配好一劳永逸"。
- 段落**长短混搭**，有的一句话，有的三四句；别每段都一样长。

## 五、AI 味红旗清单（写完逐条自查，命中就改）

| 🚩 红旗 | ✅ 改成 |
|--------|--------|
| "观点+解释+例子"每段一个模子 | 打乱：有的直接说感受，有的抛问句，有的吐槽 |
| 首先 / 其次 / 再次 / 最后 | 删掉，自然过渡或"还有个事儿…" |
| 值得注意的是 / 不可否认 / 综上所述 / 广泛应用 | 删掉或换"说真的""划重点""反正我是…" |
| 被动书面："该方法能够有效提升…" | 主动口语："我用了之后是真的快" |
| 空话："效果显著""体验良好""深受喜爱" | 具体："用了 3 天，构建时间从 2 分钟掉到 20 秒" |
| emoji 全排在句尾、每句一个 | emoji 散在关键词旁、清单前缀，数量不均 |
| 通篇没有"我"、没有时间/场景/数字 | 加第一人称 + 时间线 + 真实细节 |
| 内容完美无缺、面面俱到 | 留缺点、留主观偏好、留一句"我也还在摸索" |

## 七、与违禁词合规的协调（重要）

情绪化、口语化 **不等于** 踩广告法红线。两步都要做：

1. 用本文件的**口语情绪词**制造钩子（救命/谁懂/后悔没早知道），**不用极限词**
   （最/第一/顶级/根治/100%）。
2. 文案写完（封面文字 + `小红书文案.md`）按 SKILL.md Step 4 / Step 7 跑
   `node {skill-root}/scripts/check_banned_words.js`，命中的极限/医疗/引流词按
   `references/banned-words.md` 自然替换，**保持口语语气不变**。
